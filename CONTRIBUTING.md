# Contributing

Small, focused pull requests are welcome, but review, replies, acceptance, and releases are not guaranteed. This repository is not a support service.

Keep the project small and self-hostable. Explain the problem, the resulting behavior, and how you tested it. Run the checks described in README. Add meaningful tests for authorization, storage, migrations, and browser workflows when behavior changes. Avoid adding dependencies for cosmetic changes.

Do not submit credentials, your filled Wrangler configuration, private recordings, transcripts, Access assertions, customer data, or third-party artwork without permission. Use example.com addresses and synthetic fixtures. New contributions must be available under the project's MIT license; preserve third-party notices.

Report security concerns through private vulnerability reporting rather than public issues. See SECURITY.md. Please do not target anyone else's deployed instance.
